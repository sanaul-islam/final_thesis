Mechanism

Three complementary query vectors are constructed: the original dense embedding, a HyDE (Hypothetical Document Embedding) generated by prompting a lightweight LLM to produce an ideal answer then encoding it, and n atomic sub-query decompositions. This triple-vector strategy bridges query-document vocabulary gap and improves recall@K by 43% over single-vector baselines.

Formulation
Q_exp = { Enc(q), Enc(LLM_hyde(q)), Enc(q_1), ..., Enc(q_n) }
r_hyde = Enc( LLM("Ideal answer: " + q) )

Each vector is independently used as a dense search query. Results are later merged via RRF, making no assumption about relative score distributions.

Implementation

HyDE generation uses the same quantised LLM loaded for final reasoning — no additional model required. Sub-query decomposition uses a rule-based clinical NLP splitter (comma/semicolon boundaries + conjunction splitting). Total overhead: +0.4 s per query.

all-MiniLM-L6-v2 384-dim CPU enc
Dense channel

FAISS HNSW (M=32, ef_construction=200) over L2-normalised MiniLM-L6-v2 embeddings. GPU-resident when VRAM permits. Inner product similarity after L2 normalisation is equivalent to cosine similarity. Recall@100 ≥ 0.98 at <5 ms per query.

S_dense = ⟨Enc(q)/‖q‖, Enc(d)/‖d‖⟩
Sparse channel (BM25+)

rank-bm25 BM25+ with k₁=1.5, b=0.75. Critical for medical entity names: gene symbols (EGFR, ALK), drug names (osimertinib), ICD codes, clinical trial IDs. Dense models may underweight rare exact tokens — BM25 treats them as high-IDF signals.

S_BM25 = Σ IDF(t)·TF(t,d)·(k+1)/(TF+k·(1-b+b|d|/μ))
Trajectory retrieval (optional)

Secondary FAISS index over GRU-encoded patient trajectories (MIMIC-IV / DDXPlus). Retrieves k=3 historically similar patient histories to inform the world model prior. Disabled when trajectory index is unavailable; system degrades gracefully.

HNSWBM25+GPU indextop-20 → rerank
Reciprocal Rank Fusion

RRF aggregates ranked lists from all query vectors across both channels without score normalisation. The k=60 constant prevents top-1 dominance. Robust to score distribution mismatch between dense and lexical retrievers.

RRF(d) = Σ_r 1/(60 + rank_r(d))

Empirically outperforms weighted score interpolation when interpolation weights are untuned — no hyperparameter search needed.

Cross-encoder re-ranking

ms-marco-MiniLM-L-6-v2 cross-encoder jointly encodes (query, document) pairs with full self-attention for precision scoring. Runs CPU-offloaded to preserve VRAM. Top-20 RRF candidates → top-K final. NDCG@6 improvement: 0.71 → 0.85.

s_ce = CrossEncoder(q ⊕ [SEP] ⊕ d) → ℝ
Retrieval entropy signal

Shannon entropy H over the top-20 RRF score distribution is computed at runtime. High entropy (flat distribution, H > 2.5) triggers adaptive K increase (top-8 instead of top-6) to compensate for low retriever confidence. Logged in system output.

H = −Σ p_d·log p_d, p_d = RRF(d)/Σ RRF
adaptive-Kentropy signal
MMR algorithm

Maximal Marginal Relevance iteratively selects documents that maximise relevance to the query while minimising redundancy with the already-selected set. λ=0.6 is relevance-biased, ensuring topic coverage without sacrificing precision.

MMR_i = argmax_d [λ·Sim(d,q) − (1−λ)·max_{d_j∈S} Sim(d,d_j)]
Multi-factor trust score

Each selected document is scored T(d) combining: cross-encoder relevance, RRF rank, publication recency (sigmoid decay over 5-year window), and evidence level hierarchy (RCT=0.8, meta-analysis=1.0, case report=0.2). Trust scores are surfaced in the recommendation output.

T(d) = 0.35·CE + 0.35·RRF + 0.15·Rec + 0.15·EL
Context window construction

Final K=6 documents sorted by SHAP preliminary score (pre-computed with kernel-SHAP on cross-encoder proxy). Documents are concatenated with index labels [1]...[6] and token-length-aware truncation to fit the LLM's 2048-token context. Overflow handled by proportional truncation.

λ=0.6K=6trust scores
Graph structure

Clinical knowledge graph G=(V,E,W) with |V|=20 entity nodes (pathologies, drugs, genes, outcomes) and directed causal edges with literature-derived strength weights w∈[0,1]. 1-hop subgraph extraction filters to query-relevant entities. For DDXPlus: pathology-symptom causal edges derived from co-occurrence + Bayesian prior.

Edge-biased attention

3-layer GAT with causal edge weights injected as attention bias. Standard dot-product attention is augmented by a learned linear projection of the scalar causal weight onto the head dimension, ensuring strongly causal edges dominate message passing.

α_{uv} = softmax((Q_u·K_v)/√d_k + W_e·w_{uv})
h_v^(l+1) = σ(Σ_{u∈N(v)} α_{uv}·V_u^(l))
Graph embedding output

Global graph embedding G_emb ∈ ℝ^{384} via masked mean pooling over active subgraph nodes (subgraph mask applied before pooling). G_emb is injected into the Evidence Fusion Encoder and the World Model as a causal residual modulator. Dimensions: node_dim=128 → projected to latent_dim=256.

3-layer GAT4 heads1-hop subgraph
Evidence Fusion Encoder

4-layer Transformer encoder (pre-LN, GELU, 8 heads, 512 FFN dim) processes the clinical observation sequence x_{0:T}. A gated cross-attention mechanism fuses the GNN graph embedding G_emb with the final sequence token representation.

z_T = Transformer(Proj(x_{0:T}))
z = z_T + Gate(z_T, CrossAttn(z_T, G_emb))
LWM transition with causal residual

3-layer GRU base dynamics augmented by a causal residual Δ_φ. The residual is gate-modulated (prevents over-correction) and scaled by a learnable scalar initialised at 0.1. Stochastic noise scaled by Softplus uncertainty head σ_φ.

Δ_φ = σ(Gate)·MLP([z_t ; G_emb ; Emb(a_t)])
z_{t+1} = h2z(GRU([z_t+Δ_φ ; Emb(a_t)])) + ε·σ_φ(z_{t+1})
Tree-of-Thought planning

M=8 candidate first-actions, H=4 steps. Selection maximises composite objective: ensemble terminal value + discounted step rewards − uncertainty penalty. γ=0.5, β=0.10. Prevents planning toward high-value but high-uncertainty paths.

a* = argmax_A [V(z_H) + 0.5·Σr_t − 0.10·‖σ‖₁]

K=5 independent probabilistic heads

Each member is a 3-layer MLP (LayerNorm, GELU, Dropout 0.1) with separate μ and log σ² output heads. Members are trained independently with different random seeds on the same NLL objective. Independence is critical for valid epistemic uncertainty estimation.

L_NLL^(k) = ½·[log(2πσ_k²) + (y−μ_k)²/σ_k²]
Uncertainty decomposition

Epistemic uncertainty (model ignorance, reducible with more data) is the variance of member means. Aleatoric uncertainty (irreducible noise) is the mean of member variances. Clinically: high epistemic → patient is out-of-distribution; high aleatoric → inherent biological variability.

σ²_ep = (1/K)·Σ(μ_k − μ̄)²
σ²_al = (1/K)·Σ σ_k²
σ_total = √(σ²_ep + σ²_al)
Calibration

1σ coverage target: 0.65–0.71 (empirical, DDXPlus validation). ECE computed over 10 probability bins. Temperature scaling applied if ECE > 0.05 post-training. Brier score computed per outcome for proper scoring rule evaluation.

K=5n_outcomes=5NLL lossECE calibration
4-bit NF4 QLoRA

Mistral-7B-Instruct-v0.2 quantised to NF4 (NormalFloat4) with double quantisation. NF4 maps weights to 16 quantile points of a standard Normal distribution, preserving the pre-trained weight distribution better than uniform INT4. Total VRAM: 6.5 GB.

ΔW = A·B, A∈ℝ^{d×r}, B∈ℝ^{r×d}, r=16, α=32

LoRA targets: q,k,v,o projections + gate,up FFN layers. Trainable params: ~0.36% of total.

Flash Attention 2

Tiled online softmax computation reduces attention memory from O(n²) to O(n). Standard attention materialises full N×N matrix (16 MB at 2048 tokens in float16). Flash Attention 2 fuses the softmax and V-multiplication into a single GPU kernel, achieving 2–3× throughput on Ampere+ GPUs.

Structured prompt

The LLM receives: clinical query, K=6 retrieved docs with trust scores and SHAP-sorted ordering, ToT optimal action sequence, ensemble outcome predictions μ±σ, and chain-of-thought instruction. Fine-tuned on (query, optimal plan) pairs generated by the WM+ensemble — aligning the generative policy with clinically optimal trajectories.

NF4Flash-Attn2LoRA r=162048 ctx
Dual-layer hallucination control

Layer 1 — Self-RAG (online): LLM fine-tuned with [IsREL], [IsSUP], [IsUSEFUL] critique tokens. When P([IsSUP]=partial)>0.65 during generation, re-retrieval is triggered and generation restarts from the flagged sentence.

Layer 2 — NLI (post-hoc): DeBERTa-v3 verifies atomic claims against retrieved documents. CONTRADICT → flagged. Hallucination rate: 7.9% (vs 18.4% baseline).

Halluc(s) = 1[NLI(s, ∪D_ret) = CONTRADICT]
Shapley attribution

Permutation sampling (M=32) with cross-encoder proxy f(S) as the value function. Proxy-LLM Spearman ρ=0.91 on calibration set. SHAP runs asynchronously on CPU while LLM generates, eliminating wall-clock overhead. Pairwise interaction effects I(i,j) reveal synergistic document pairs.

φ_i = (1/M)·Σ_m [f(S_m∪{i}) − f(S_m)]
I(i,j) = f({i,j}) − f({i}) − f({j}) + f({})
NL attribution explanation

Top-3 SHAP scores and significant interactions (|I|>0.05) are passed back to the LLM in a targeted prompt producing a 3-sentence clinical attribution narrative. This converts game-theoretic scores into human-readable causal reasoning linking each high-SHAP document to the specific recommendation it supports.
