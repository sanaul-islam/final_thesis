# Thesis — Making AI More Trustworthy

This folder contains the full thesis manuscript: *Making AI More Trustworthy:
Context Labelling and Original-Source Tracking for Clinical Question Answering*.

## Files
- `main.tex` — the complete thesis (LaTeX `report` class, six chapters).
- `references.bib` — bibliography (BibTeX).
- `main_ieee_backup.tex` — the earlier IEEE-conference version, kept for
  reference. Overleaf compiles `main.tex` only; this file is ignored.
- Figures are read from `../outputs/figures/paper/` (generated by
  `scripts/make_paper_assets.py`).

## How to compile

### Option A — Overleaf (recommended, no local install)
1. Create a new Overleaf project and upload `main.tex` and `references.bib`.
2. Upload the figure PDFs from `outputs/figures/paper/` (or zip the whole
   project) so the `\graphicspath` resolves.
3. Set the compiler to **pdfLaTeX** and press *Recompile*. The `report`
   class and all packages used are available on Overleaf by default.

### Option B — Local
Requires a TeX distribution (TeX Live / MiKTeX) with `pdflatex` + `bibtex`:

```powershell
cd paper
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

## Regenerating the numbers and figures
From the project root, in the venv:

```powershell
# 1) retrain + recompute all metrics (writes outputs/metrics_report.json)
python scripts/retrain_and_eval.py

# 2) regenerate every figure used by the thesis (real data + model)
python scripts/make_paper_assets.py

# 3) validate citations, refs, environments, figures, braces
python scripts/validate_paper.py
```

The result tables in `main.tex` mirror `outputs/metrics_report.json`,
`outputs/comparison_results.json`, `outputs/metrics/data_stats.json`, and
`outputs/metrics/train_test_metrics.json`. If those numbers change after
retraining, update the corresponding values in Chapter 5.

## Thesis structure (chapters)
1. **Introduction** — background, rationale, problem statement, objectives,
   methodology in brief (with full architecture diagram), scope and challenges.
2. **Literature Review** — RAG, world models, uncertainty/interpretability,
   clinical QA resources.
3. **Requirements and Planning** — specifications, societal/environmental/ethical
   impact, standards, project management (Gantt), risk management, economics.
4. **Design and Implementation** — methodology overview, and data collection
   (cleaning, transformation, integration, reduction, summary).
5. **Result Analysis** — performance, design-solution analysis, final
   adjustments, statistical analysis, comparisons, discussion.
6. **Conclusion** — summary, contributions, future work.
