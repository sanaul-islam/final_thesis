1 The Three Datasets

GRAPES-SHAP learns from and is tested on three public medical datasets. Each plays a different role: one teaches the world model, one is the evidence library for retrieval, and one is the exam used to evaluate the final system.

4 Inside the World Model — Every Layer's Job

A world model learns the “rules of the world”: given the current state and an action, what is the next state? Here is exactly which layer does which job, in order.

#Layer (code)What it doesShape
1 CausalResidual
a_emb + MLP + gate Computes a small “nudge” δ to the state caused by the action, gated & scaled (×0.1). This is the causal effect of doing something. z → Δz (256)
2 Action Embedding
nn.Embedding(50,256) Turns the discrete action ID (one of 50) into a 256-d vector the network can use. a → (256)
3 GRU Core
GRU(512→512, ×3) The heart of the world model. A 3-layer recurrent net carries memory across time and produces the next hidden state from (state+δ, action). (512)→h(512)
4 h2z Projection
Linear+LayerNorm+SiLU Maps the GRU hidden state back into the 256-d latent state space zt+1 — the predicted next state. h→z' (256)
5 Decoder
MLP 256→256→64 Translates the abstract latent state back into a readable observation (the 64 patient features) — lets us check the model “understood” the world. z→obs (64)
6 Sigma Head
MLP + Softplus Outputs uncertainty (σ) for every latent dimension — how unsure the model is about its own prediction. z→σ (256)
7 Reward Head
MLP 512→128→1 Scores “how good” a transition was — used by the planner to compare action paths. (z,z')→r (1)
🔄 How rollout() imagines the future
Starting from the current latent state z₀, the model applies an action, predicts z₁, then feeds z₁ back in with the next action to predict z₂, and so on — without ever seeing real observations. This “dreaming” is what makes it a true world model: it can simulate consequences purely in its head.
🎯 What the model is trained to minimise
Loss = reconstruction (predicted next state vs real next state) + a tiny smoothness term (states shouldn’t jump wildly) + a tiny σ term. In numbers: recon + 0.01·smooth + 0.001·σ. Low reconstruction error (MAE 0.040) means it predicts the next state very accurately.

🟦 INPUT stage

The patient’s 8-step symptom trajectory (8×64) plus the action taken at each step. The Encoder + KG-GNN compress this into a 256-d latent state that captures the clinical picture.

🟪 MIDDLE stage

CausalResidual adds the action’s effect; the 3-layer GRU carries memory and rolls the state forward. This is where the model simulates the future — the core of the world model.

🟩 OUTPUT stage

The Decoder turns latents back into readable features; the 5-member ensemble outputs a diagnosis distribution + calibrated uncertainty; the reward head scores the path for the planner.

7 Scope & Honesty (for research integrity)

Being precise about what this world model is — and isn’t — matters for a thesis defense.

✅ What it genuinely is

A real latent world model in the Dreamer / Ha–Schmidhuber family: it has a latent state, an action-conditioned transition (GRU + causal residual), a decoder, an uncertainty head, a reward head, and it performs latent rollouts (“imagination”) for planning. The architecture is legitimate and complete.

⚠️ Caveats to disclose

  • Trajectories are semi-synthetic (built from static DDXPlus by revealing symptoms step by step).
  • Actions = “reveal evidence,” not real treatments.
  • The reward head is not supervised by a clinical target.
  • Outcomes are diagnosis probabilities, not survival/readmission.
📝 Honest framing: describe it as a proof-of-concept latent world model / model-based reasoning module, not a clinically validated treatment-outcome simulator. That claim is fully defensible.
